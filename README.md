#### **Descrição do Projeto**



Aplicativo desenvolvido em Java no Android Studio para registrar abastecimentos e acompanhar o consumo de combustível de um veículo.



#### **Funcionalidades**



* Cadastro de abastecimentos com data, hodômetro, litros, tipo de combustível e preço por litro.
* Cálculo do consumo médio em km/L.
* Cálculo do custo por quilômetro (R$/km).
* Média de quilômetros percorridos por dia.
* Comparação entre os preços da gasolina e do etanol para identificar a opção mais vantajosa.
* Armazenamento de dados utilizando SQLite.

#### 

#### **Tecnologias utilizadas**



* Java
* Android Studio
* XML
* SQLite
